# 🎮 Tic-Tac-Toe Game in Python

A simple **command-line Tic-Tac-Toe game built with Python** for two players.

This project was created to practice Python fundamentals such as loops, functions, lists, conditional statements, exception handling, and user input validation.

## ✨ Features

* 🎯 Two-player Tic-Tac-Toe
* 🧩 3×3 game board
* 🔄 Alternating player turns
* ✅ Win detection for rows, columns, and diagonals
* ⚠️ Prevents players from selecting an occupied position
* 🛡️ Handles invalid inputs using exception handling
* 💻 Runs directly in the terminal

## 🛠️ Technologies Used

* **Python 3**
* Lists
* Functions
* Loops
* Conditional statements
* Exception handling
* User input

## 🎮 How to Play

The board positions are numbered from **1 to 9**:

```text
1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9
```

Enter the position where you want to place your symbol.

For example:

```text
Enter position (1-9): 5
```

Players take turns placing their symbols until one player wins or the board is filled.
